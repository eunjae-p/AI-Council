# AI Council V0.4

## 로컬 웹앱 실행 (권장)

`AI-Council-Web.cmd`를 더블클릭하면 로컬 서버가 시작되고 브라우저에서 `http://127.0.0.1:8765`가 자동으로 열립니다. 인터넷에 공개되는 웹사이트가 아니며 이 PC에서만 접속할 수 있습니다.

- 최종 결론을 가장 먼저 보여줍니다.
- 토론 과정은 접어서 필요할 때만 봅니다.
- 네 단계 진행 상태를 실시간으로 표시합니다.
- GPT는 `gpt-5.6-sol`, Claude는 로그인 계정의 기본 모델을 사용합니다.
- **앱 종료** 버튼을 누르면 로컬 서버가 종료됩니다.

한 번 입력한 질문에 대해 Codex CLI와 Claude Code CLI가 독립 답변을 만든 뒤, 서로의 답변을 검토하고 개선된 최종 답변을 내는 Windows용 자동 토론 버전입니다.

## 요구 사항

- Windows PowerShell 5.1 또는 PowerShell 7 이상
- 구독 계정으로 인증된 `codex` CLI
- 구독 계정으로 인증된 `claude` CLI

별도 API 키와 추가 패키지는 사용하지 않습니다.

## 데스크톱 앱 실행

`AI-Council.cmd`를 더블클릭합니다. 질문 입력창에 여러 줄로 질문을 쓰고 **자동 토론 시작**을 누르면 됩니다. `Ctrl+Enter`로도 시작할 수 있습니다.

- 화면 상단에 GPT 모델 `gpt-5.6-sol` 고정 상태가 표시됩니다.
- 진행 막대와 현재 단계를 실시간으로 표시합니다.
- **중지** 버튼으로 현재 CLI 호출을 종료할 수 있습니다.
- GPT와 Claude의 초안 및 상호 검토 결과가 한 화면에 순서대로 나타납니다.
- 전체 토론을 반영한 최종 결론이 화면 상단에 별도 표시됩니다.
- 초안과 검토 과정은 **토론 과정 보기** 버튼으로 펼치거나 숨길 수 있습니다.
- **최종 결론 복사** 버튼으로 마지막 답변만 바로 복사할 수 있습니다.

데스크톱 앱은 Python 기본 GUI만 사용하므로 별도 패키지 설치가 필요 없습니다.

## PowerShell 실행(선택 사항)

프로젝트 폴더에서 질문을 인수로 전달합니다.

```powershell
.\council.ps1 "양자 컴퓨팅을 한 문단으로 설명해줘"
```

질문을 생략하면 반복 입력 모드가 시작됩니다. 처음 한 번만 실행한 뒤에는 `Q>` 뒤에 질문만 계속 입력하면 됩니다. 빈 줄이나 `/exit`를 입력하면 종료됩니다. 긴 한글 입력에서 커서가 겹치는 현상을 줄이기 위해 입력 프롬프트는 짧게 표시됩니다.

```powershell
.\council.ps1
```

기본 제한 시간은 CLI별 180초입니다. 필요하면 변경할 수 있습니다.

```powershell
.\council.ps1 "질문" -TimeoutSeconds 300
```

## 동작 구조

1. GPT와 Claude가 원 질문에 독립적으로 답합니다.
2. GPT가 두 초안을 비교·검토하고 개선된 답변을 냅니다.
3. Claude가 초안과 GPT 검토를 다시 평가하고 개선된 답변을 냅니다.
4. 각 단계의 진행 상태와 총 네 개의 결과를 순서대로 표시합니다.
5. 명령 누락, 제한 시간 초과, 0이 아닌 종료 코드가 발생하면 오류와 표준 오류를 표시하고 프로그램을 종료 코드 1로 끝냅니다.

Codex는 사용자의 현재 기본 모델 설정을 그대로 사용합니다. CLI 실패 시 API로 우회하지 않습니다.

두 CLI의 출력은 UTF-8로 읽으므로 Windows PowerShell 5.1에서도 한글이 깨지지 않습니다.
